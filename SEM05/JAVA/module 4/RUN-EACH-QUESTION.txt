  (user=root password=root, see MvcCrudApp.java)
  LIST:   http://localhost:8080/MvcCrudApp/crud
  ADD:    http://localhost:8080/MvcCrudApp/crud?action=add&name=Ravi&marks=80
  UPDATE: http://localhost:8080/MvcCrudApp/crud?action=update&id=1&marks=90
  DELETE: http://localhost:8080/MvcCrudApp/crud?action=delete&id=1
